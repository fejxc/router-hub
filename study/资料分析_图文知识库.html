基础概念

把时间和四个核心量认清
DA-01

现期量与基期量

#
题型识别

问“去年 / 上年同期 / 以前是多少”，求基期；问“今年 / 现在 / 以后是多少”，求现期。

核心关系现期 = 基期 × (1+r)；基期 = 现期 ÷ (1+r)
图解 · 先找比较起点与终点

基期是比较起点；同比、环比仅改变比较的时间区间。

⚡ 考场算法

先确定同比还是环比。若下降 d%，将 r 写成 −d；已知增长量时，基期=现期−增长量。

! 易错提醒

小 r 时 A÷(1+r)≈A×(1−r)，只是估算；基期和差应分别还原再加减。

例题速看2025年为1100，同比增长10%，则2024年=1100÷1.1=1000。
DA-02-AMOUNT

增长量

#
题型识别

问“增长了多少亿元 / 比上期增加多少”或“减少了多少”。

核心关系Δ = 现期−基期 = 现期 × r ÷ (1+r)
图解 · 增长时 +1，下降时 −1
正增长 20% = 1/5
1200 ÷ 6 = 200
增长量 = 现期 ÷ (5 + 1)
下降 20% = 1/5
1200 ÷ 4 = 300
减少量 = 现期 ÷ (5 − 1)

两个式子的“现期”都在分子；下降算出的 300 是“减少的绝对量”。

⚡ 考场算法

正增长 r≈1/n：Δ≈现期÷(n+1)；下降幅度=1/n：减少的绝对量≈现期÷(n−1)。

! 易错提醒

下降时增长量为负，但“减少量”常指正的绝对值；不要把现期×r当成精确值。

例题速看现期1200，增长20%=1/5，增长量=1200÷6=200。
DA-02-RATE

增长率

#
题型识别

问“同比增长百分之几 / 增幅 / 降幅 / 增速”。

核心关系r = 增长量 ÷ 基期 = 现期 ÷ 基期 − 1
⚡ 考场算法

增长率比较，能直接比较“现期÷基期”；相同结构都减1，不必再算。

! 易错提醒

是基期n倍→增长率n−1；比基期增长n倍→增长率n。降幅比较通常比负增长率的绝对值。

例题速看由100增至130，增长率=30%；由100降至80，增长率=−20%。
DA-01 / DA-02

平均增长量与预测

#
题型识别

问“年均增加多少 / 按每年增加X预测 / 保持增速预测”。

核心关系平均增长量=(末期−初期)÷n；固定增速：未来=当前×(1+r)ⁿ
⚡ 考场算法

n按时间间隔取：2016→2020是4个间隔；固定增长量是加法，固定增长率是连乘。

! 易错提醒

“年均增长量”和“年均增长率”不是一回事；“首次超过”使用严格大于。

例题速看2016年100、2020年180，年均增长量=(180−100)÷4=20。

增长率进阶

判断是跨期、相加、相乘还是相除
扩展节点

间隔增长率

#
题型识别

问“今年相对前年 / 两年累计增长率”。

核心关系R = r₁+r₂+r₁r₂；反推 r₂=(R−r₁)÷(1+r₁)
图解 · 两段增长率不能直接相加
100前年×1.10110去年×1.20132今年

总体增长 = (132−100)/100 = 32%，多出的 2% 来自交叉项 10%×20%。

⚡ 考场算法

同向串乘：(1+r₁)(1+r₂)−1；三期以上继续连乘。

! 易错提醒

r₁r₂项能否省略取决于选项间距；不要把年份数量当成增速段数。

例题速看连续增长10%、20%，间隔增长率=10%+20%+2%=32%。
DA-06

年均增长率

#
题型识别

问“2018—2023年年均增速 / 年均增长率”。

核心关系(1+r)ⁿ = 末期÷初期；n=末年−初年
图解 · 2019 到 2021 只跨过 2 个年度间隔
1002019×1.101102020×1.101212021

年均增长率满足 (1+r)²=1.21。这里 n=2，不是3。

⚡ 考场算法

年份差相同，可直接比较“末期÷初期”；选项接近用平方/立方验证。

! 易错提醒

总增长率÷n只是近似，通常高于精确复利年均增长率；2018→2023的n为5。

例题速看2019年100、2021年121，(1+r)²=1.21，故r=10%。
扩展节点

混合增长率

#
题型识别

整体=部分甲+部分乙（如全国=城镇+农村；全年=1—11月+12月）。

核心关系R=(Aa+Bb)÷(A+B)，A、B为各部分基期量
图解 · 混合增长率向基期量大的那边靠拢
10% · 甲17.5% · 整体20% · 乙
甲基期 100乙基期 300 → 权重大

偏向关系来自基期量加权；不能仅靠现期量大就判断靠哪边。

⚡ 考场算法

整体增长率介于两部分之间，并偏向基期量较大的一方；可用线段法反推比例。

! 易错提醒

是“基期量加权”，不是现期量加权；先确认两部分互不重叠且合起来正好是整体。

例题速看基期100、300，增速10%、20%，整体增速=17.5%。
扩展节点

乘积增长率

#
题型识别

总量=单价×数量；产量=面积×单产；部分量=整体×比重。

核心关系R = a+b+ab；b=(R−a)÷(1+a)
图解 · 先判断题目是 +、×、÷ 哪种结构
＋
整体 = 甲 + 乙混合增长率：基期加权
×
总额 = 单价 × 数量乘积增长率：a+b+ab
÷
人均 = 总额 ÷ 人数比值增长率：(a−b)/(1+b)
⚡ 考场算法

将每个因子的增长系数相乘：(1+a)(1+b)=1+R。

! 易错提醒

“加法混合”与“乘法增长”不是一类题；双因子增速较大时不能忽略ab。

例题速看单价涨10%、销量涨20%，销售额增32%，不是30%。
重构版补充

比值增长率

#
题型识别

指标=A÷B，如人均、单价、单位面积产出、某项比值。

核心关系比值增长率 = (a−b)÷(1+b)
⚡ 考场算法

比较比值升降只看a与b：a>b则升，a<b则降。

! 易错提醒

该式求“增长率”，不是比重提高了几个百分点。

例题速看收入增20%、人数增10%，人均收入增长约9.09%。

DA-03

比重

#
题型识别

问“占……多少 / 比重 / 占比 / 提高几个百分点”。

核心关系现期=A/B；基期=(A/B)×(1+b)/(1+a)
图解 · 两期比重：比“百分数”还是“百分点”
20%
现期比重
−
18.33%
基期比重
+1.67个百分点

部分 200 / 整体 1000；部分增长 20%，整体增长 10%。两期比重差 ≠ 比重增长率。

⚡ 考场算法

两期比重升降只看a、b；比重变化量=(A/B)×(a−b)/(1+a)。

! 易错提醒

a是部分增长率、b是整体增长率。比重差以“百分点”表示，不是比重增长率。

例题速看部分200、整体1000，a=20%、b=10%；现期20%，基期18.33%，提高1.67个百分点。
DA-04

平均数

#
题型识别

问“人均 / 每X的Y / 单位面积产量 / 平均每家”。

核心关系现期平均数=A/B；基期=(A/B)×(1+b)/(1+a)
⚡ 考场算法

平均数增长率=(a−b)/(1+b)；两期平均数差=(A/B)×(a−b)/(1+a)。

! 易错提醒

平均数差的单位仍是元/人、件/户等；增长率才用百分数，两者公式分母不同。

例题速看收入增20%、人数增10%，人均指标增长率≈9.09%。
DA-05

倍数与比例

#
题型识别

问“是几倍 / 多几倍 / 超过几倍 / 占比是否高于75%”。

核心关系是n倍：A/B=n；多n倍：A/B−1=n；占75%：4A=3B
⚡ 考场算法

判断阈值可交叉乘：A/B>75% ⇔ 4A>3B（B>0）。两个平均数倍数=(A/B)/(C/D)=AD/BC。

! 易错提醒

“比……增长n倍”不是“是……的n倍”；计算倍数之前确认大小对象。

例题速看A=300、B=100，A是B的3倍，A比B多2倍。

比较类题型

先定性、再估算、最后必要时精算
DA-02-AMOUNT

增长量比较

#
题型识别

问“谁增长最多 / 增长量最大 / 减少最多”。

核心关系Δ = 现期 × r/(1+r)
⚡ 考场算法

正增长时，现期和增长率都更大者，增长量也更大；一大一小再代公式。

! 易错提醒

增长率最大≠增长量最大；有下降时先看题目问负的增长量还是减少量绝对值。

例题速看A现期1200、增长10%；B现期900、增长20%，B的增长量150，大于A约109。
DA-07

分数大小比较

#
题型识别

问“哪个占比最大 / 平均值最高 / 增速比较 / 排序”。

核心关系A/B 与 C/D：交叉比较 AD 与 BC（B、D>0）
⚡ 考场算法

同分母比分子；同分子比分母；同向变化比较“分子相对增幅”与“分母相对增幅”。

! 易错提醒

交叉相乘要确保分母为正；差分法等是可选工具，不要在差值很小时盲估。

例题速看比较110/200与120/220：前者55%，后者约54.55%，前者更大。
DA-03 / DA-04

两期比重 / 平均数升降

#
题型识别

问“比重比上年上升还是下降 / 人均同比提高还是降低”。

核心关系A/B 的两期方向：只看 a−b 的正负
⚡ 考场算法

a>b：升；a=b：不变；a<b：降。

! 易错提醒

方向判断可秒选；问“差多少”时必须继续计算，不要仅用a−b作答案。

例题速看部分增12%，整体增8%，部分占比必然提高。

速算工具

DA-09

百化分

#
题型识别

给现期和增长率，尤其增速接近特征分数。

核心关系r=1/n：增长量=现期/(n+1)；下降绝对量=现期/(n−1)
⚡ 考场算法

优先记25%=1/4、20%=1/5、16.7%≈1/6、14.3%≈1/7、12.5%=1/8、11.1%≈1/9、10%=1/10。

! 易错提醒

14.9%不是精确1/7；靠近选项边界时需修正或精算。

例题速看增长率约11.1%，现期约1000，则增长量约100。
DA-09

截位直除

#
题型识别

两大数相除、且选项分离明显。

核心关系选项差大→先取2位；较近→取3位 / 更多
⚡ 考场算法

先观察选项；只保留影响结果的有效数字，算完再回看误差。

! 易错提醒

“两位 / 三位”是经验，不是保证。选项紧邻或结果靠近分界时应提高精度。

例题速看若候选答案约0.41与0.58，粗估够用；若0.491与0.494，需更精确。
DA-02 / DA-09

现期×r的近似误差

#
题型识别

算增长量时想直接拿“现期×增长率”。

核心关系高估误差 = 现期×r²/(1+r)（r>0）
图解 · 看似只差一点，实际足以错选
粗估：现期 × 10%
110
准确：1100 × 10% ÷ 1.1
100

粗估高了 10；相邻选项若落在 100 与 110 之间，不能凭粗估作答。

⚡ 考场算法

当r较小、选项距离很大，可先用现期×r定位数量级。

! 易错提醒

正增长时现期×r必高估；r=10%时不是“只错0.1%”。

例题速看现期1100、r=10%，粗算110，真实增长量100，误差10。
DA-09 / 重构版补充

选项放缩与阈值判断

#
题型识别

题目问“是否超过某比例 / 达到几倍 / 大于某值”。

核心关系A/B>75% ⇔ 4A>3B（B>0）
⚡ 考场算法

把除法改成乘法或用上下界夹逼；判断阈值不必先求精确商。

! 易错提醒

放缩方向不能反；要让整个估算区间都落在目标一侧才能确定答案。

例题速看判断370是否超过480的75%：4×370=1480>1440，故超过。

五步做题流程

#

四大陷阱

#
题型识别

选项说法出现同比 / 环比 / 万与亿 / 累计与当期 / 部分与整体。

核心关系时间 × 单位 × 口径 × 概念
⚡ 考场算法

分别核对：基准时点、换算单位、统计总体、题干描述是否一致。

! 易错提醒

“增长最快”一般比增长率，“增长最多”一般比增长量。

例题速看题问2019同比，不能直接使用2020环比。
DA-08

综合判断题

#
题型识别

问“下列说法正确 / 不正确 / 有几个正确”。

核心关系能直接查找的先查；复杂运算留后
⚡ 考场算法

先检查概念、时间和单位，再完成较容易验证的选项，最后处理精算项。

! 易错提醒

一个选项算对不代表全部验证完毕；“正确个数”需逐项判断。

例题速看四个选项先排除明显年份错项，再判断剩下的比重与增长量。

考场实战

重构版补充

估算精度与选项间距

#
题型识别

选项极为接近或估算结果恰在两项中间。

核心关系估算误差应明显小于相邻选项分界距离
⚡ 考场算法

先看最接近的两项，判断估算是否可能跨中点；有风险则多算一位。

! 易错提醒

靠近分界点时不能用“约等于”硬选。

例题速看粗估结果100，选项99和101时，估算误差±3不足以区分。
考试应用

反向检验

#
题型识别

算完时间允许时快速检查，尤其复杂基期与比重题。

核心关系基期×(1+r)≈现期；部分比重和≈100%
⚡ 考场算法

验算符号、量纲和数量级；多部分统计要先确认不重叠。

! 易错提醒

并非所有统计分项都完备，也不一定能做比重和=100%的校验。

例题速看算出基期1000、r=10%、现期应为1100。
考试应用

解题优先级

#
题型识别

遇到多种解法且时间紧。

核心关系定性秒判 → 百化分 / 线段 → 截位 → 精算
⚡ 考场算法

先保证正确率，再压缩计算量；综合判断题先处理最容易核验的选项。

! 易错提醒

原稿5—6分钟/篇仅为教学参考，不是官方强制标准。

例题速看问比重是否上升，只比较a与b，不先计算两年比重。

增幅 vs 降幅增长率带正负号；降幅大小通常比较绝对值
百分点 vs 比值增长率两个百分数相减用百分点；比值的相对增长率要除以1+b
混合增长率 vs 混合比例前者基期量加权；后者按对应分母规模加权
年均增长量 vs 年均增长率平均差值（线性）vs 年均复利
同比 vs 环比、累计 vs 当期先核对比较基准和统计区间，再代公式
